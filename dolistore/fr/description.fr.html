Connectez Dolibarr à toutes vos applications

Boutique en ligne, caisse, CRM, logistique : chacune de vos applications détient une partie de votre activité.
Le module Splash fait de Dolibarr le point central de toutes ces données et les garde synchronisées en permanence, sans ressaisie ni export manuel.

Pourquoi Splash pour Dolibarr ?

🛒 Toutes vos ventes réunies

Les commandes et factures de votre site e-commerce, de votre point de vente ou de toute autre application connectée arrivent directement dans Dolibarr, quel que soit le canal de vente.

📦 Des stocks justes, partout

Un stock mis à jour dans Dolibarr l'est aussi sur tous vos canaux de vente : fini les commandes de produits en rupture. Gérez un stock global, ou les stocks de chaque entrepôt séparément.

👥 Une fiche client unique

Grâce au Linker Splash, les profils d'un même client répartis dans vos applications sont identifiés et fusionnés. Une modification faite à un endroit est répercutée partout.

📊 Une gestion financière simplifiée

Commandes, factures et paiements sont importés automatiquement, avec les bons taux de TVA et les bons comptes bancaires. Votre suivi financier devient plus simple... et sans effort.
 

⚡ La puissance de la plateforme Splash

Pas de connecteur figé ni de correspondances à saisir à la main : Splash analyse chacune de vos applications connectées, découvre les données qu'elle sait échanger, et configure automatiquement la meilleure synchronisation possible pour votre écosystème. Ajoutez une nouvelle boutique ou un nouvel outil : il trouve sa place, sans développement. Et vous gardez toujours la main pour affiner chaque règle.

Pensé pour vos usages réels

✅ Configuration automatique : le module détecte votre configuration Dolibarr (multi-prix, variantes, multilingue, multidevise, multi-société, champs supplémentaires) et s'y ajuste de lui-même, sans paramétrage.
✅ Import sans friction : commandes « invité » rattachées à un client par défaut, client reconnu par son e-mail, produits identifiés par leur référence (SKU).
✅ TVA maîtrisée : les codes TVA sont reconnus et, à défaut, retrouvés à partir du taux, selon votre dictionnaire Dolibarr.
✅ Adresses propres : les adresses saisies sur plusieurs lignes sont découpées automatiquement pour les applications qui les attendent en plusieurs champs.
✅ Multilingue : libellés et descriptions produits synchronisés dans toutes vos langues.
✅ Vos règles s'appliquent : le module agit au nom d'un utilisateur dédié et respecte la politique de droits de Dolibarr.

Installation en quelques minutes

  1. Téléchargez le fichier module_splash-x.y.z.zip, sans le décompresser.
  2. Dans Dolibarr, allez dans Configuration > Modules / Applications, onglet Déployer/Installer un module externe, et envoyez l'archive.
  3. Activez le module Splash, dans la famille Interfaces avec des systèmes externes.
  4. Saisissez l'identifiant et la clé de cryptage de votre serveur Splash, puis vos paramètres par défaut : langue, utilisateur, entrepôt...
💡 Installation impossible depuis l'interface ? Copiez simplement le dossier splash de l'archive dans htdocs/custom. Toutes les étapes sont détaillées dans la documentation.
